# 正畸模型分析 · Ortho Model Analyzer

一个纯前端的正畸模型测量与间隙分析工具。上传口扫 STL，在模型上标点，得到牙弓长度、牙齿总宽度、Spee 曲线深度与 Bolton 比值，再把这些数带进间隙收支表，看清一个病例缺多少间隙、方案能补上多少。

**在线使用：** https://kyring151.github.io/ortho-model-analyzer/

单文件、无后端、不联网、不上传任何数据。除了首次加载页面本身，运行过程中不发起任何网络请求。

---

## 功能

### 一、模型测量（STL）

- 上下颌各一个独立视窗，支持拖放上传 `.stl`
- 左键拖拽旋转、滚轮缩放、右键平移
- 曲率伪彩：平坦面象牙白，牙尖与嵴提亮，邻接沟、窝、牙龈沟压暖灰，牙与牙的分界会自己浮出来
- 两次单击闭合一颗牙，逐颗累加得到**牙齿总宽度**，每颗可单独删除重测
- 沿牙弓连续点选得到**牙弓总长度**，点越密越接近真实弧长
- 单击落点带曲率吸附，自动往邻近的邻接沟上靠
- 一键 Bolton 分析：需要上下颌各点满 12 或 14 颗，输出前牙比、全牙比与差值
- 一键下颌 Spee 深度：逐颗取颊侧最高点，投影到矢状面后量中切牙到最后磨牙连线的最大偏离

### 二、间隙分析

需要间隙分三项，各自可追到唯一来源：

| 项目 | 计算方式 |
|---|---|
| 牙列拥挤度 | 牙齿总宽度 − 牙弓总长度 |
| Spee 整平 | 下颌曲线深度 × 整平系数（上颌不计） |
| 内收需求 | 目标唇后退 ÷ 软组织内收系数 |

方案假设由你自己填：拔牙获得间隙、邻面去釉、横向扩弓、磨牙远移。工具只做加减法，给出上颌与下颌的余量或缺口。

### 三、病例存档

- 输入即自动存草稿，关掉网页再打开还在
- 手动存档可保留多份病例，随时切回
- 导出 / 导入 JSON，可跨电脑搬

## 边界：它不做什么

- **不输出治疗建议。** 是否拔牙、拔几颗、支抗怎么设计，全部由临床医生判断。工具只做算术。
- **不做牙齿自动分割。** 依赖人工标点，误差看得见也改得动。
- **不处理 Bolton 以外的牙量不调、牙周风险、根吸收、颞下颌关节等因素。**
- 数值只作临床参考，不构成诊断依据。

## 已知局限

- 曲率着色按每个模型自身的曲率分布归一，不同扫描精度、不同网格密度的模型色调会有差异。
- 40 万面以上的模型会跳过着色，退化为素模，吸附同时失效。
- Spee 深度取的是几何最高点，不是解剖学颊尖；扭转牙、大面积修复体、牙龈覆盖牙冠时可能取错。
- STL 与标点不随病例保存，重新打开需要重新上传模型。

## 数据与隐私

所有数据存放在浏览器 localStorage，包括患者姓名、年龄、检查日期与测量数值。不上传服务器，不接入任何统计或追踪。换电脑、换浏览器、清理浏览器数据都会导致本地记录丢失，重要病例请用「导出」存一份 JSON。

## 技术

单文件 HTML，内置 three.js r128（MIT）用于 STL 渲染与拾取。曲线着色、曲率吸附、Spee 深度、Bolton 计算均为手写实现。
